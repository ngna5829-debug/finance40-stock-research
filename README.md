# Finance40：金融书籍研究库与美股研究台

40部金融、投资、经济和理财原著的逐章研究资料，以及美股联网研究网页。

[浏览40本书籍索引](BOOKS.md)

- 607个原章或连续正文单元，提炼正文1,699,590汉字。
- 每章至少2000汉字、每书至少20000汉字；原交付验收最短章2005字、最短书20847字。
- 40个单书专家定义、4个协调组、1731条有原文证据的规则。
- 研究池为最近可得市值前100只美股普通股/ADR，服务运行时每5分钟请求更新。

## 下载完整库

进入本仓库的 [Releases](https://github.com/ngna5829-debug/finance40-stock-research/releases/tag/v5.0.0)，下载 `finance40-stock-research-complete.zip`。
完整包包含40份全本PDF、原文、提炼、专家定义、图像证据、版本许可及验收材料，约1.94GB。
核验值见 [SHA256SUMS.txt](SHA256SUMS.txt)。GitHub自动生成的 Source code ZIP 是源码快照；40份全本PDF位于上述完整包。

Git目录保留可浏览的源码、文本原文、逐章提炼和专家资料。扫描PDF、研究图片及历史候选副本在完整包中保留。部分文本证据引用的原图需下载完整包后查看。

## 启动网页

需要已有Python 3.9或以上版本；Windows还需系统具备Python `zoneinfo`可读取的时区资料。

1. 将完整包解压到本项目目录，保持 `stock-app-v5` 文件夹结构。
2. macOS双击 `stock-app-v5/一键启动选股台.command`；Windows使用 `stock-app-v5/启动选股台.bat`。
3. 或在终端进入 `stock-app-v5`，运行 `python3 bridge.py --port 8775 --open`。
4. 服务启动后访问 `http://127.0.0.1:8775/index.html`。

电脑需保持联网并运行服务。网页每5分钟轮询；行情源的精确延迟未知。
静态阅读可直接打开 `stock-app-v5/library/书本深读档案.html`。Windows启动器未在原交付中实际执行验收。

## 资料与运行范围

- 40份专家是单书知识角色定义。默认使用确定性规则和证据检查，实际语言模型调用记录为0；可选多轮模型会话需已有本机Ollama模型。
- 书本阅读与股票方向预测分别记录；预测收益尚未校准，全部原书策略未自动化。价量资金指标为代理量，未接入真实机构账户净流入。
- 16份全本PDF由完整电子原文重排。原版身份、来源许可、OCR疑字、跨版恢复和历史数据冲突详见逐本审计；不承诺所有扫描字形均已逐字校勘。
- 全本PDF类型、来源及哈希见 `stock-app-v5/library/全本PDF来源与校验.json`；当前资料清单见 `repository-files-manifest.json`。
- 第三方原著及资料保留各自来源、署名和许可说明；公开仓库不改变这些资料的原有许可。

仓库准备基于已验收的V5资料，准备仓库不计为重新阅读全文或重新执行模型会话。原交付与实时行情快照日期分别保留。
