# 第一集第十五章　再论互惠

原章 XV. Reciprocity Again；原TXT3152–3221行完整实际读，无独立原注。第一集第十章问是否要互撤障碍，本章另问贸易是否须逐对同额互买，二者分别分析。

本章的互惠问题比第十章更具体。圣克里克问，外国是否一定买入同它卖出一样多；栋巴斯勒问，英国生产者需要物品时，为何必从法国而非世界别处采购，并且等值于出口法国的量？巴斯夏认为这种疑问把国家交易想成两个人每件货互相直接换的方式，却没有观察货币使用的日常实际。它不是反驳所有对外融资风险，而是先问同一直接买卖关系是否为交换可行的必要条件。

作者让人看农民买鞋、帽、法律建议和课程时，并不要求鞋匠、帽商、律师、教师恰好以同额买他的粮。农民先把粮卖给愿意买的人，取得支付工具，再向不同的人购买自己需要的东西。分工网络因此不需要每对参与者同时满足对方的需求。第一集前面几章已将交换同专业化连起，这里再加货币让对手分离，能回应英国客户不直接回买法货的疑问。当前引的是原生活例，没有为这些职业编造一份真实多边账。

他说千百乃至万次交易里几乎没有直接物换物，语气是强调货币的广泛使用，而非做过十万样本调查。“从引入钱后从没人要求同额”也是很强概括，现实契约或某些交换可以设限定，原章不提供全样本。专家可引用通常不必逐对同额这一机制，不能把这些夸张当易货比例为零的历史统计。反例即使显示某一次直接交易存在，也不推翻媒介使间接网络可行的较窄命题。

作者先建立封闭国内模型。农民把小麦送本国市场，以可得最高价卖出，取得硬币；他把币形容为不同额度的指令，日后可按自己需要、在竞争下从全国物品中取得。这里全国储存池是市场比喻，不是国家真的将全部物品集中入库，硬币也未在此具名赋予对某仓库具体物品的法律兑付权。不能把这段直接当成前面另书足额保管金票模型；比喻功能与法定权利需要分开。

农民卖出时得到的金额，限制其后来按同单位买物的能力。作者在“操作最终结束”条件下说，他取出的价值会等于贡献，消费与生产价值恰相等。这可以在把所得全用于后续采购、同一计价和没有别的权利变化的简化网络理解；不是证明每一年消费等于当年生产。若农民保存币、投资、收到赠与、借钱或纳税，阶段账就不同。原全书讨论资本积累，不能在此把“最后花掉”条件无声改成不允许储蓄的经济定律。

向国际开放后，每个人把自己的产品送的是一般世界市场，取得的币来自何国、后来买的东西来自莱茵或比利牛斯哪一边，都不必须同原售货方向配对。作者说每人的供给与取得价值对应，汇集成国家也是如此。本章没有给汇率或同一金属标准的具体条款，现代应用不能让所有外币面额不换算便相等，也不能把国内售价和进口到岸费忽略。共同计价与可支付关系是模型发挥作用的前提。

本次可用一个明确标为现代说明的链条理解，而不归原书新增事实：甲向乙卖一种物，甲向丙买另一种，丙也可能向其他人出售；只要所得或融资形成可接受支付，甲乙不必两边全额互买。这说明多边清算和直接双边货物平衡不同。它不证明每个链都自动闭合、每一债都按时履行；实际收款、债务和币种仍需账目。不应为了直观把三方凭空编成原历史公司，更不能从此报一项实时国际资金流。

“价值相等”也不同于满足和实物量相等。双方按一笔货价成交，数值账可能同额，但所得物品适用性与个人满足可以不同；原前章反复强调消费者为什么愿意选更高成果。若把按报价相等误当同量劳动、同数量或双方完全同效用，就混用作者不同位置的概念。尤其本章没有计量技能和工时，不能用它证明每一国的劳动小时在贸易中一比一兑换。

作者说开放后面对较大的购销市场，便多了完成有利交易的机会。这个“机会更多”是选择集合扩大，不必意味着每位旧卖家每笔交易收入都提高；竞争也会改变价格。它支持不要仅为要求原客户回买而关闭其他客户，不足以预测哪家公司成功。要确认实际机会需货物、品质、运输、履约和对手需求；世界市场在文本中不是一个能无条件付钱的保证人。

最后他认真加入一个极端反对：若大家联合不接受某个人的商品，他便不能从大众取得所需；国家也可能这样。他没有在这里靠无条件市场保证否认排斥，而说若国家无法从一般市场取得所需，就会停止向其供给，转为自己生产，落入孤立。这里他将拒收产品与无法取得所需作相互结果描述，并未给排斥发生概率。这个保留对于专家很重要，不能只取前面的扩大机会而声称永远不会被市场阻断。

其讽刺结论是，保护者为怕将来可能落入孤立，先主动强迫国家实行孤立，仿佛先施加所怕后果就能避免它。这是比较前置确定成本和未来风险的理由一致性问题，不等于任何准备或备份都无意义。若现代方案保留外贸又建立有限替代，而不是提前完全孤立，便不是同一条件；若关键物品风险有可信证据，也须衡量不同路径。原章没有在此建风险模型，专家不能从讽刺定一个无需库存或绝不自产的比例。

国家汇总从个人推过去，还需留意边界。居民可以借贷和转让资产，进出口又有货物、服务、运费与时间差。原“最终每人完全平衡”不能证明每个国家同一年双边货贸必须平衡，也不能证明赤字必亏或必赢。第六章已显示海关估价与商人账不同，此处应继续保留那项知识。把不必甲乙互买理解为国际偿付可以永不需要来源，也是超出原义；来源应以实际权利和资源另外说明。

本章的原钱比喻同已读P13可以外部对照：P13区分金属本身与对金属的票，本章把币叫市场指令，是说明买卖连接，而未建法律保管权。两者不是自动冲突或完全相同，分别识别对象才有意义。没有全印扫描和他书全文新增，不以这个对照增加阅读册数或专家票；当前P14也不能在读完这一短章后计完整一本。

在公司层面，销售地与采购地不同不自然是坏账；需看合同收入、币种、支付时点及能够买到的投入。英国客户没有买同额法货，不足以证明法国出口商损失，出口商仍可能用回款买第三地资源。但政策、汇兑和付款断裂可能改变结果，要真实财务与行情才能判断股票。本文不把比喻池子当机构净流，不将当代标价或收益填入原叙述，专家仍保持未运行状态。

这一章较稳妥规则是，货币与交易网络使直接双边同额互购不成为交换的一般必要条件，较大选择集合可能提供更有利购销；最需限定的是个人消费生产“每例恰等”及风险下无需准备的可能误读。面对跨书，以储蓄、融资、汇率、结算和排斥执行的证据修正具体结果；若只是要求每个买家同额反买，就没有回应原媒介机制。缺这些输入，对现实支付能力、孤立风险和证券裁决弃权。
