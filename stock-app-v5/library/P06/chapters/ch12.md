# 第十二章　银行国家垄断：竞争、现金需求与管理激励

原章XII. STATE MONOPOLY IN BANKING，写于1918年8月。固定原文本第4439—4902行，464行分1—232、233—464完整输出及语义审读，无截断。Addis、Webb引文与Withers评价分别归因，未把预测和实际法定保证混同。

第十二章开篇主动更新第六章的判断。几个月前他觉得合并通向垄断还远，如今合并进展使可能性更近，支持者希望国家接管，反对者也担心集中。这不是可以忽略的重复论述，而是随着对象变化收紧原来乐观。专家不能固定引用第六章“竞争未成危险”去覆盖八月观点，也不能说作者已经观测一国只有一家银行；本章仍讨论趋势与可能后果。原文第4453—4463行是整本观点修订的明确依据。

Addis在Edinburgh Review的引文担心大银行各自更大，英格兰银行怎样仍提高利率防金外流；巨型私行若失败，政府可能不得不动国家资源救，故几乎有政府保证，再到政府控制和国有化。这个“实际上保证”是预期与政治机制，不是已经核实全额法定担保合同。资产规模比央行大也不能单独证明货币政策必失效，需要边际资金、准备金、工具和依赖结构，白芝浩分析最终资源而非只看规模，正能提出这些问题。专家应该把集中、公共承担与工具能力分开，不能由引文替任一家银行认证安全。原文第4464—4482行需要保持条件语气。

Webb在另一报刊同月文章认为合并是资本主义阶段下经济必然，法律不能阻，最终应把利润垄断变国家公共垄断。他标题是防银行垄断，却实际赞组织统一，反的是私人逐利，他与Withers分歧在控制和目的，不只银行数量。原书给大量引文，本次没有另阅两篇原报完整上下文；引用中的必然也没有全面历史样本。专家若评估现实趋势，要查合并、市场范围、准入与替代，不把“阶段必然”当已验证预报，也不误将Webb每项观点署成Withers支持的规则。

Webb的第一效率渠道是全国一个银行令内部转账不流失总存款。不同银行会因地区、产业、声誉和客户转移失存款，各须可用储备；一体内部变更只需分支临时现金，所以少闲置资金、更稳定。Withers承认平常转移可省一些柜台现金，却反对由此消除准备金：公众若想更多现金在自己口袋，即使国有银行也会流出。他举1914邮政储蓄银行受提款，客户因囤币或支票不便而取现。内部客户换账与客户离开银行系统，是不同边界，专家缺行为和最终支付资源不能将它们净额合掉。原文第4518—4596行列方案和作者反驳。

这个区别也修正第十三章杰文斯普通存提款错开的乐观假设，而不必说两位作者完全相反。正常条件和共同恐慌可能同时在同一制度中存在，实际准备须看压力、合同、现金来源和补充时间。国家能提供某种最终工具也要核制度与实际可用，不单靠国有名称。原章没有说政府不能发纸，但其讨论基于当前现金与黄金支付条件，不能把它直接套到任一现代法币体系。知识节点可提出问题，不能填固定最低百分比或挤兑概率。

Webb另一说法是股份银行规模扩大，把管理交给固定薪专业职员，旧有个人股东经理影响减小，正在形成无利益管理。Withers认为这个说法将来可能被修改，转引Addis赞德国董事的行业与国外项目知识，批英国董事年老、赶火车或只看荣誉和少费，提议适当报酬配责任。引文对人物行为的强描写不是本轮独立观察全体银行董事。固定薪不跟每笔业务收利润，也不等于没有奖金、晋升、权力或声誉利益；专业管理与公正中立仍需查实际激励和监督。原文第4554—4670行不能被读成“有薪管理天然无私”。

德方奖金比例也有分母条件。引文在留准备与付普通分红后，让几家银行董事取剩余净利一定份额，另有亲自承担责任的合伙人比例；它不是本金年收益、不是交易佣金，也不是给所有德国银行相同薪酬。监督法律与赔偿责任是Addis对当时制度的描述，未核原法规，不用于现行董事法律判断。作者想说明报酬和责任吸引专业人，而非按一个比例即可给治理认证。与白芝浩常任专业人员和大董事会信息缺口相对照，可要求实际知识、权力、独立性及决策记录，不能只看头衔、年龄或薪金。

Webb对垄断行为的担忧则被Withers部分认同。少竞争可能提高小账户收费、不给利息、不接小额业务，贷款也可能偏好某些人，对急需者索高价。他认为已有五大行即可能通过协议产生垄断效果，不必等真正只剩一行。专家因此不能只以挂牌机构数多于一排除市场势力，也不能把这一点加回第六章就说作者始终判集中无害。他称这部分有不少真理，仍认为大营业量薄利可让私人机构希望便宜服务，垄断不必然限制数量。两种预测都需实际收费、准入、客户替代和成本核证。原文第4671—4734行构成实质承认和限定。

国家接管是否必改善，作者更怀疑。去股东利润不意味着便宜服务自动出现，官员也有费用、迟缓与其他动机。他引用邮政、电话、供水来反驳，电话接管后亏损被他当负例，又明确邮政缺可比私人对象。专家不能把这些并称全有独立对照，也不以亏损认证全部服务变坏，公众用途和成本要同口径。Webb说国家化未必是部长领导公务机构，Withers却预测负责人会发展同样公务性格，属于行为猜测不是已试方案结果。原文第4736—4768行有证据范围和制度分歧。

Webb随后提出分开银行职能。收款、账户、托管证券、收股息、代付和汇款可合到邮政储蓄成为全国公共服务；借贷、贴现则由专门金融机构按行业做，私有或行业联合都可试。政府把存款一部分投定期国家债，主体借给政府地方公共事业和这些中介；中介需可靠财政、未缴资本、成员连带保证或资产抵押作保护。所谓未缴资本和保证是将来请求权，需成员能力及压力关联性，不因字面“可靠”就认证现金。专家必须核政府对存款人的提款责任与资产回收时间，而不是把分工后的风险消失看成既成事实。原文第4770—4851行列完整分离方案。

作者承认考虑后方案没有必然不可实行之处。政府保留常规收付和储备，私人经营较难、需判断的借贷；这是他对对手方法的一项真实认可，不应删掉只留讽刺。他担心连接处摩擦：政府给存款利息依中介支付，中介需借款者利率减自己利润和风险保护，两种意见调整可能慢。需要定价、期限、责任与变更机制，原文没有试验测实际摩擦。专家可解释接口依赖，但不能预言每次都会失灵，也不能认分机构就完成精确风险隔离。

末尾作者想象如今柜员快识签交钱，变公务员后可能慢核签名、余额，公众更烦、纳税人最后补亏。这种情景与上面承认可行应同时保留：他的结论在服务与管理表现上强烈负面，却不是方案已实行后记录。签名、余额核查也涉及保管与安全，快慢不能是唯一效果；人员、系统、激励和错误率都需要真实资料，本章没有比较。不能继承其“亲切商业人”与“邮局官员”形象来给当今职业群体评级，也不把去股东成本全换成公共福利的乐观假设照收。

本章完成的知识链，是合并趋势更新、内部转移与外部提款区别、专业薪酬不等于无利益、寡头协议也可能有垄断效应，以及银行功能分离仍需连接与责任。作者和两位引文者之间存在具体分歧，不是三个同向验证票。必要资料包括存款行为、最终现金、竞争收费、治理、资金期限和制度执行，缺则弃权于政府保证、储备节省或公私净益认证。其他书或实际记录可修正行为推断与方案评估，不能仅凭一张表或所有权名称决定。当前没有银行系统实验、选股或回测，章稿按一九一八年八月知识保存。
