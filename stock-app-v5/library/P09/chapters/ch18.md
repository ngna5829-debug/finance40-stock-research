# 第十八原始章节　济贫税（原章号XVI）

来源：原XVI、顺序第十八章，原目录纸354—362；6401—6547行完整读，原注26书末10603—10629行全部实际阅读。注对不可分离资本改善与真正租的界限有重要修订，已纳入正文而非只列注号。尚无原扫描或同期法条核准。

济贫税在本章不是一种可凭名称确定承担者的税。作者先归纳局部农业税、一般利润税和纯租税的不同结果，随后说这项税同时有它们的性质，可在不同条件下落消费者、资本利润或租。必须查农民同厂商的利润受相等还是不等影响，及农民能否抬产品价补偿特殊部分。这是本章的实际分析程序；“济贫”说明公共用途，不自动说明税基、价格和产权的反应。

若农业、制造业利润同比受影响，共同部分可归一般利润税，不因相对业务回报改变而单独推高粮价；农业额外承受的部分则可能抬粮价。若无法获得这种价补，才可能减租。在此提一般利润税不动价格时，仍需同前章货币来源和价值设定并读，不能把简略回顾当取消其他条件的独立证明。真正需要的是可比较的相对负担，而不只是两行业各交多少镑。

税自称按农民租额征，若真的如此，无租或租很少者应不缴或少缴，纯租税逻辑便可能让地主承担。但作者认为实际并非按付地主的租，而按土地年度价值，价值无论由地主还是承租者资本创造都计。因此，自耕无租不等于免于这项估值税，长租固定金额也不等于新增改良完全免税。这是原书关于当时实际制度的主张，本次没有把它升格为已核当年全部地方征法的法条解释。

两个农民各付年租一百，一人五十亩肥地，一人一千亩贫地，未改良时可付同样税。贫地农民凭长租花费施肥、排水、围栏后，税随年度价值提高，却未按原租一百封顶，甚至可等于或超过租。若这是他作改良前能预期的费用，粮售价不补普通利润与新增税，改良不会被做；在作者这套事前边际决策中，价格需包含费用。因此，“税超过租”不能靠算术断定全由地主减租吸收。

这个例子也不能解释所有已有投资：原文是在可预期税的前提下判断新投入会否发生，后段另讨论投下去后才加的税。将两段混用会把事前保普通回报变成每个事后地主或承租者都必能完整补偿。需要记录改良日、租期、税评日、估值与当时信息，才能确定是哪一种；只见已经排水后的现租不能证明全部税早被预期。

若地主自己改良，称租的金额从一百到五百，也要有能覆盖额外资本补偿和估值税的产品价，论证方向不因付款者名称不同而变。若此时制造资本也同程度受税，农业特殊劣势又消失，两边普通利润都少，不能再以相对利润为理由令粮独涨。作者原句强调让资本从一业去另一业的是利润相对落差，非单看绝对利润少；它没有讨论各业共同回报低到全部投资不再发生的完整阈值，不能推广为绝对收益任何时候无关。

实际税制在他看来偏压农民，因为农业按实际所得生产价值评，而制造仅按建筑价值，不看所用机器、劳动和存货。因此农业相对利润下降，可在供给调整时把差额传至产品价；反过来若制造业更重，也可令其商品价增加。这不是预设农民天生更能转嫁，而是比较税评遗漏的对象。精确实证仍需同口径资本、利润与估值，厂房账面低也不能未经核实就当其整个税负低。

在农业扩展社会，税共同部分由资本雇用者通过利润降负担，农业特殊部分由粮消费者付。若最差地每单位产量税更高，统一粮价补最差地后，好地可能多补；现租期先归承租者，后来租约更新转给地主。这同土地税章固定税例连续，也直接否证“济贫税一定损害地主”的单句结论。它仍要求同价粮市场、可扩展边际和续租竞争，并没有给现实每一地主的净收益。

停滞或倒退、资本难从土地撤出时，新加税的结果不同。承租者曾把资本融进土地，年度估值提高后现租期必须付新税，即使利润低于一般也不能拔走排水、地力等投资。租期满后多转给地主，是作者在旧投入收益与续租条件的推论，不是承租人立即能从原租中扣任意数额的法律权利。没有真实合同和资产资料，应区分已支付、未来议价及经济租变化。

假如可撤设备并降低土地年值，税也随之少，产物供给减又能涨价补税，就不必减租；但作者承认有些资本不可撤，这比例的税在现期归农民、期后归地主。因而可拆装设备与不可分离改善，不能都列“固定资本”就假设同样流动。制造资本若相对容易转出，则类似条件下还可能以商品价调整，显示一个社会的不同资本退出能力可使税同时有不同归宿。

原注二十六对这些分类作了书内重要修订。作者承认早先把纯租与为地主投资支付的所谓租分开时，未充分区分投资方式。一次投入后不可分地融入土地、永久提高生产力的资本，其此后补偿严格具有租的性质、受租的变化规律；最初仍须预计不少于同额资本别用收益，才肯投入。但一经完成，不能永远把收入当尚可撤出的新资本普通利润。

这项修订同第十章“建筑和改良补偿不是纯租”必须并读。不是所有人造改良永久变租：建筑和其他会损坏、需续建的投入只给有限期好处，不能永久增加真正地租。第二章关于原有地力的定义也因这里永久改善收益性质获得更复杂边界。专家若只记初定义，在本章再遇年值税便误判；若只记后注，把任何机器、房屋都当永久地租，同样错。

由此需分清投资决策前的机会成本、完成后的可撤性以及收益持续需要多少更新。某排水工程最初要可比利润才能决定做，事后沉入土地的回报却可能被新税侵蚀；一栋房屋还需维修和重建，新供应的资本要求仍存在。这个分析不必借现代术语代替原文，但现代称沉没投入时须标为解释，而不能宣称作者给了今日完整资产评估准则。

本章没有核算救济带来的劳动健康、需求或公共服务的完整利益，而是聚焦征法和生产条件。第五章反对济贫制度的规范主张，不能替代这里逐类归宿分析；也不能因本章某情形让地主得益，便推作者肯定该救济制的全部社会效果。用途、制度公平和生产税基属于相连但不同问题，现代需要受助者、财政与就业资料再评价。

若与P04危机中资本和信用流动的知识交叉追问，普通利润低之后现实能否融资退出、长期契约是否锁住资本，是这里特别需要证据的地方。它不让另一书替本章投第二票，也不能把市场价格已涨当作无成本迁移已发生。个体有意换行业与社会实际完成再配置之间有等待、损失及资金约束，本章虽承认可撤与不可撤，并未给全部过渡数据。

这一章的专家输入必须包括真实税评对象、土地纯租和改善补偿、租约期限、税或改善的先后、各行业同口径负担、边际产量和资本可撤比例。缺一组关键量时可解释几种可能而不能给最终百分比，更不能据税名对农业股和地产股直接打分。永久改善与可耗损改善的原注修订保留为原作者条件更新；未核同期制度、法条及历史数表不进实验，本次没有当前交易判断。
