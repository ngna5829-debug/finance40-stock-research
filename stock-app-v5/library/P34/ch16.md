# 第十六章　保证金融资改变义务与持有能力，不能只看初付金额

原文：第十六章印刷页61–64，source/chapters/ch16.txt，2,799字符全文已读。二成普通保证金、三成至五成建议均属1922年书内数值；现代券商和法律要求不据此确定。

<!-- 正文开始 -->
作者说多数股票交易者融资买入，普通最低保证金约为购买价两成，因为银行通常愿借股票市价八成。他用客户付两成、经纪为其他八成筹钱并把股票质押给银行，说明客户、经纪与银行三方的资金链。原书没有列实际银行与证券范围，不能将八成当所有品种都被接受的保证，更不能移作今天固定标准。知识专家必须分别识别客户自有资金、经纪义务与银行融资，不能只见买入成功就认为有完全自有现金支持。

书中也有抵押资格限制：某些股票不被银行接受，客户不应期待经纪仍能融资售给他；经纪若答应，作者怀疑它可能经营价格赌博式的bucket shop。这是风险提示，不是逻辑上已证明所有不通过某银行抵押条件的股票交易必为骗局。不同资金来源、券商合同和真实成交情况还需核查，本章没有这些资料。原文用看起来像的语气，不能升级成已经查实某机构违法；第十八章要另读，不能只凭其标题完成身份判定。

作者回应融资就是赌博的批评，指出其他业务也有相似借款。全价买股票，却向自己的银行借购买款八成并抵押股票，在经济上仍像融资买；住房付两成、借八成，也有自有资本与债务组合。这项比较主要解释资金来源，不证明各种借款合同风险一样。谁最后持抵押、什么现金用来还、何时可要求更多保障与被迫出售，是不同交易的关键。书本专家不能从都借钱就得出同样安全，也不能因借款不在券商便把它当无杠杆。

原书比较住房与券商合约：股价接近欠款额时经纪有出售权，房贷常有约定期限，作者说到期前贷款人不能同样卖掉住房，同时又称原则上差别不大。这个法律与执行简述未附合约、违约条款、地区和当时判例，不能作为今天住房或证券融资的法律保证。现代独立分析须要求实际合同与现行制度，不因为一项贷款有固定期限，就推定期间没有任何违约、追加或处置条件。本档案不凭这段给具体抵押法律意见。

在同一章，作者又说只放最低保证金，股价稍跌就可被要求补钱。这与接近欠款时出售是不同触发，不能把前一句误译为在股价仍高于债务时绝不受追加影响。初付、维持要求与最终亏空要分开。原章没有完整合同演算，当前专家须取有效要求、可用资金、证券价格及其他余额；只存一个最初两成数字，既无法确定何时追加，也无法判断客户能否支付。

现代独立算例可以用一百单位资产、八十债务、二十自有净值说明杠杆：暂不计利息费用，资产跌到九十，自有净值成十，资产跌一成而初始净值损失一半。若资产涨到一百一十，净值成三十，增加十相对最初二十是一半。它只是解释收益和损失都被放大，不是原文实际客户结果，也不是当前允许借八成的推荐。原作者谈更大利润可能性，不能让模型只计算上行情形、隐去同样的下行尺度。

同样资产一百、债务五十、自有五十，跌十时净值成四十，初始净值损失两成。这项现代独立对比说明厚保证金减少借款比例，而非绝对不损失；不能只凭五成就保证不会追加或资产不会失效。具体追加仍由实际合约决定，不能把算例的净值比当原书或现行维持门槛。其意义是保持融资规模、自有风险本金与资产涨跌的分母一致，防止用资产收益率冒充客户资本收益率。

作者最明确的实际建议是别放不足的保证金。如果无法随时应付追加，应缩小购买并多放自有资金。他说金额依交易而变，常建议三成至五成，有时不低于五成，还有时建议完全不要融资买。厚保证金的原意思因而可以确认，也用于校正第十四章；它不是提高杠杆或尽量买满借贷能力。将一般范围与有时禁止一起保存，比只选择两成最低或利润最大的一句更符合原章。

这项建议涉及两种能力。愿意接受浮亏不等于有现金补款，账户外的收入与支出、其他债务和资金到账时间都可能改变可承受性。作者说随时准备，现代独立审核应索取实际可动资金，而不是客户一句保证。这里没有规定一笔储备现金，不能擅添收入倍数或安全垫比例再署作者；系统自己的预算和风险门可以要求资料，并在未知时停止强结论。书本知识无权用低估假设替代资金证据。

作者说想完全免忧者可在股票很低时全款买、拿证书放安全箱。它减少对经纪短期融资的依赖，却不能证明经济风险全无。低价仍需第四章真实价值的依据，第六章失败公司未因全款购买复活；安全箱保护文件与价格、公司经营不是一件事。现代独立分析还需检查是否在别处借钱完成全款，才能知道整体债务。原文免忧是劝告强度，不应作为系统已确认资产保本的标签。

结尾又说股票低时用较充足保证金风险很小、利润可能大很多，作者看不到不利用的理由。这与前文有时完全不要融资的限制需同时保留。低如何确定、估值若错怎样、资金突然收紧如何，并未在此全部解决；本章沒有回测、极端样本和成本账。可以报告作者对可靠低价融资的倾向，不能赋一个小风险概率。第七章脚注上涨过快暂停保证金买，是实际文本中的条件变化，对无时点的始终适用结论构成约束。

现代参考资料也不能被混入作者声部。SEC投资者教育公告提醒，保证金账户可能损失超过初始投入，并且根据相关协议，券商可能在没有先行通知或等待客户补款的情况下处置证券；公告是工作人员教育说明，不是我们对任一账户已作法律裁定。[SEC保证金账户说明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-29)本次已核。这段仅说明旧书的两成惯例及简化合约不能替代当前合同，不在此推荐任何融资。

可调用输入必须包括证券身份、真实抵押资格、总购买与借款金额、自有资金及来源、初始和维持条款、追加与出售权限、利息费用、可动用补款能力以及价值判断和反证。期限是融资合同与实际付款窗口，而非任意五日预测。只有股价和最初存款，不能确认风险很小或没有追加要求；只有银行接受抵押，也不能确认证券实际价值。对此书专家应弃权于执行许可和个人杠杆，而可以解释资金链与原意。

反方可质疑全款是否暗含别处借款、厚保证金是否被翻成高杠杆、股票低是否真低于价值，以及借住房类比是否忽略合同差异。第三轮应将原作者时代范围、独立算例与当前契约证据分开，保留缩小购买和补款能力的限制；未知时弃权，不用利润放大来覆盖市况与风险门。任何返回都应明确是否只解释知识、是否缺当前资料，不能据本章替用户下单或将历史保证金比例当今天通行法。
