# 第四章：资本化的条件与货币收入的内生性

原章 The Capitalization Theory and the Value of Money，纸本72–79，全文2977–3165行及注58–61/全文18429–18478。全部正文与四条原注已读。本文为原创转述；纸页锚据PG完整HTML，尚未声明此章逐字目视核验。

第四章从一个看似适合资本化的问题出发：货币也是资本工具，能为使用者持续提供交换服务，那么是否可以把服务收入折现成货币自身的价值？作者以可替代性说明，同一人使用钱后通常得到另一枚钱，币材磨损又可能由国家承担，所以在他讨论的法律和实践条件下可以暂抽去某一枚钱的耗损。并非任意纸钞、账户或货币制度都永远无损。他认为交换像制造一样能创造价值，货币帮助交换，短期资金市场中的利率便可理解为这种具体工具的租价，而不全是抽象资本的纯时间利息。专家应保留“服务是什么”与“谁付什么租价”，不能只因都称利率便混成一项无条件收入。（原文2982–3006行；纸本72–73）

用租金估资本价本来是可理解的。作者设一块城市地每年带来一百美元、永续不变，暂忽略风险以及土地所有权附带的社会声望等服务。第一笔一年后、下一笔两年后，各笔未来收入虽名义金额一样，现值并不相同。若折现率百分之五，无限序列的和是二千，等于一百除以零点零五。这个结果能独立复算，但依赖首笔在一年后、支付永续固定、贴现为正且其他条件暂不变化。它不是一块真实土地的已查公允价，也不能把预计短期年收益乘二十套到有期限或不稳定收入的证券。（原文3008–3038行；纸本73–74）

蜡烛、圆盘和墙上影子的比喻，用来显示两个假定独立因素：圆盘大小如年度收入，蜡烛与盘距离如贴现率，影子如资本价；收入大则影子大，贴现率高则影子小。这是关系比喻，不是以几何图替代风险分析。作者特意说此处不全面检验资本化理论的有效性或全部限制，只问它能否解释货币价值。专家若借用了这个模型，就应承认这里没有研究完整利率期限结构、增长、违约、税与资本返还；不能用本章没有讨论为理由把这些真实输入设成零。（原文3038–3051行；纸本74）

货币情形的第一难题，是服务收入与折现率并非相互独立。货币短期租价不是长期利率同一个数，但作者认为长期平均及市场预期中二者常共同变化。若短期租价长期提高、足以令资本化模型想提高货币资本价，长期利率也可能上升而抵销。他预告极短借款、稍长借款及长期利率差别的解释要到货币功能章才完整展开，不能在本章就把未来理由当已读证据。也不能把他所述常见长短关系当永远上斜的现代收益率曲线或认定随借随还利率总是最低。（原文3053–3082行；纸本74–75）

注五十九把“纯利率”本身列为方法装置。对于三年以上不同期限都有一个纯利率，作者说很可能只是简化的想象；本章暂允许质量相同的二十年、三十五年及永续贷款差别被抽去。他不是已经测得一个可输入模型的统一无风险数字。现代独立分析也须指出：相关并不会让折现的算术关系自动失效，但若解释变量与待解释对象共同决定，就不能用它们当独立外因证明货币价值。需要联合模型和额外识别证据，不能以一个利率升降方向包办币值变化。

第二难题比共同变化更深。普通承租资产在此简化模型里，其资本价像被动影子，由租金和折现率决定；货币却须先有价值，才能被接受而发挥货币服务，服务收入部分依赖货币已有价值。作者说影子反而成为原因，把“因为可用于交换而值钱”与“因为先值钱才可用于交换”的循环提出。他没有在本章完全解开，只把问题转交后续渡渡鸟骨和货币功能分析。专家应允许暂存未解问题，而不是宣称作者已经由资本化证明任何没有既有社会支持的代币都能成为货币。（原文3084–3101行；纸本75–76）

第三难题又回到计价单位。若固定美元收入在未来的价值预计降低，现值会受到超过单纯等待时间的折减。作者区分时间使同一价值远期看来较小，与未来一百美元本身预计意义较小；后者可使名义利率高于纯利率，以补偿预期的货币损失。计算时可以把这部分放入名义贴现率，理论解释却须区分。它并不保证每个市场能准确补偿通胀，也没有给今天某债券的实际利率。专家更不能同时把收入全额按同一预期贬值调整，再在利率中重复加同一项而不说明口径。（原文3103–3126行；纸本76–77）

因此名义现金流与实际现金流应保持一致的测量基础，是本次现代研究解释，不是原书交付的现成通胀公式。比如名义一百仍按合同付款，不代表购买能力未变；按本章模型算出二千，也不等于当时即可用它买同样数量的消费品。所需证据是付款币种、现金流日期、固定或可调的金额、名义或其他口径的贴现率以及相关风险。若输入混用了今天报价、历史购买能力和不同期限利率，应停止给精确估值，先把口径拆开，而不是用漂亮的小数掩盖条件不一致。

作者还试图证明所假定的固定货币价值不是物价平均数倒数。假设利率下降，在其资本化结构下，土地、股票、债券、房屋以及持续提供服务的其他资本品价格会升，平均价格也升。如果将平均价格上升自动定义为货币贬值，又以货币贬值解释名义利率上升，便会说利率下降引起利率上升。他将这个矛盾用作支持绝对价值概念的理由。这里需要读者接受他的前提、同一利率概念与因果顺序；它不是任何两个现实利率先后反向波动均可被判逻辑错误的证据。（原文3128–3152行；纸本77–78）

注六十特别说平均价格按权重计算、资本品在所讨论交易中占主导，还预告后面交易量章节会展开。不能把这个价格集合静默换成当代消费者物价指数；当前指数是否含金融资产、房价和怎样加权，需要另外定义。现代独立挑战可以要求权重、货币贬值识别和利率期限是否一致，检验原推理究竟是模型内冲突还是变量换义。若实际资料显示资本品价格涨而消费篮子未涨，就不能由这句话判资料不可能，只能重新核作者所指的价格集合。

章末将供求、成本和资本化归为以货币取得精度的工具，因而不容易切开货币这个磨刀石。作者借此解释为何数量论流行，并预告还要考察边际效用；本章的结论针对他见到的理论表述，不是禁止任何未来货币估值模型。注六十一又承认资本化存在有关个体利率与社会利率的争议，他为当前问题采用一般版本、抽去费雪等人彼此分歧，不展开全部利息争论。这个方法限定不能丢掉，也不能因作者某处批评费雪便说他从未借用费雪的其他分析。

这章的专家适用期是现金流期限和融资、定价机制的解释，没有固定每日买卖窗口。它需要完整支付日程、收益是否实际产生、币种、利率口径和期限、风险、收入与折现的共同决定因素。只给一条股价日线、一个年化收益或一个政策利率，就应对合理资本价和货币价值弃权。可检验的现代命题包括相同风险期限下收入预期改变是否影响报价，以及名义重定价与折現口径是否一致；未检验前不能宣称已有效。反方若指出预期收入并非独立、利率根本不是统一纯利率，或产品没有永续权利，专家应缩小估值范围并重新计算。它应在现金流假设被否证时撤回结论，而不是把利率下降的单一叙述转成所有股票都应上涨的多数票。
