# 《The Value of Money》全书综合与证据附录

本书是一部从货币出发的经济理论书，英文初版1917。完整作品计一本、一个单书专家，二十五原章及原章附录不拆分计书。章节正文72881汉字，另有49条规则；本综合与专家说明不计入章数和最低正文要求。全部数字文本、597注及索引已实际读完，已完成独立全文语义复核及必要修正复核，源限制仍保留；652页扫描未作逐字视觉全量校勘。

作者的主线先在第一至五章区分价值与价格、货物与钱单位，以社会关系解释有效需求、资本化和效用理论的限制。第六至十九章逐步检验强数量理论额外要求：固定钱信用比、独立速度、独立交易、被动价格。其批评针对强版本的因果和口径，不能概括成钱数量永远无关，也不能由恒等式未证因果推恒等式算术无效。

二十章归纳并承认缺口，二十一、二十二章将接受和可售性、金的非货币需求及七种服务拆开。二十三、二十四章说明信用将难售权利变更可用形式，银行液态资产与储备依用途、期限、市场及制度变化。二十五章再统一价值变动与价格关系，并要求终局收益和到达终局的设备、组织、融资及社会成本同看。此路径提供研究问题、条件与反证，没有原书定义的五日、二十日股票预测或校准概率。

几个必须跨章保留的修订与争点：

- 第七章、十八章、二十四章否定严格比例，却承认数量与黄金供给有作用；不能只抽反数量论句。
- 第十二章个人平均周转与全社会周转的质疑有权重边界；正确余额加权可会计一致，不能说所有加权方法都错误。
- 第八章批价格乘数量的量纲，本次区分每单位报价与纯数量；单价乘量可得金额，其他口径/权重批评仍须独立判断。
- 第十九章主文对纽约份额强断言，长注406、411却承认间接估计需全年直接分类数据与可能修订；二十章摘要不能覆盖这项未解。
- 第四、十五章的理想资本化须带二十五章注585：资本值可黏滞、反推租金及支持贷款，非每次收入变立即被动响应。
- 金饰需求可能韧性高，却时尚、财富分配、用途统计均未给可信普适数；注466拒精确用途规律。
- 第二十二章对艺术金与钱服务的均衡明确未解；附注493也拒给印度卢比多原因精确份额。
- 银行抵押、证券流動性与借短投长在二十三、二十四章有乐观强句。本次以跳价、追缴、共售、回收期限和利率变动作独立反证，不归错作者。
- 二十四章注544把证券抵押再贴现政策建议收为理论例示，要求先压力试用；它不是本档案当代法律或政策指令。
- 战争、关税或可观察私人资本收益不等于社会福利；作者也承认欺骗品牌和垄断等可害。原有民族、性别、遗传先验没有现代验证，不进入个人评分。
