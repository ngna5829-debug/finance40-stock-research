# 第三章　习惯通货如何列在银行资产负债表上

本章将前两章的抽象货币讨论放到一张大银行典型表，先拆责任，再拆资产，最后回到支票的习惯地位与应急货币。作者想说明不是只有入库金镑在循环，银行可让抵押财富成为可支付余额；这种习惯通货很重要，却在恐慌时有兑现问题。档案必须同时保存产生与失效两面，不能只选表的平衡便声称安全，也不能只见金准备少便宣布必倒。

表的Dr一侧有授权资本三千万，实际issued资本三百万、准备基金一百一十二万五千、current/deposit等欠款三千七百五十八万余，客户承兑三百一十五万余，未到期贴现利息回扣转下期五万余与净利润二十二万余。授权数在左边列示并未进入合计，不能把三千万加进去当已经到账的现金。作者说issued资本为股东已付并已在业务中使用的款，属于其对这张表的解释，不从词面推所有今天的发行资本都已足额缴清。

他称资本为对股东的或有责任，股东求股利；准备基金多由历年利润累积并投资最好证券，用于价格贬值和其他意外；净利润是股东可分股利的钱。三项都不能与存款人随时要求提款混同，准备基金也不是同数现金另锁在箱。这个辨析尤其重要，因为书内另有黄金准备争论，reserve fund这个权益/累积项目和现金准备并非同一个词值。今天做比较先取实际财务口径，不可从表中任一reserve名称自行当可立即支付。

最大责任项目三千七百五十八万余在作者看来是真正业务资金、银行欠客户的款，却不是公众全部直接交入的钱。明确的机制是每笔新贷款会增加存款，借款者账户被记入可用额，可以开支票，所以抵押财富通过银行转为通货，放贷越多存款账户越大。这句话应与第二章他否认从无创造财富同时保留：他承认余额增加，却从财富背书定义credit。不能把他的整套立场缩成所有存款只是老金镑搬家。

承兑责任按作者说法有客户抵押证券实际覆盖，待客户另交资金偿付银行。Cr侧又有相同金额的客户承兑责任，形式上对应同额，不代表没有银行对票据持有人的支付与客户对银行的返款两条义务。原书说此业务须很小心，也只是适度收入来源；现代独立审核因此应核客户能力、抵押处置及两端到期，不把同数contra当风险已经数学抵消。未得客户契约与实际回款，不能认充分担保。

Cr现金及英格兰银行余额为五百九十九万余，可分银行日常柜台、金库所需硬币纸钞及存央行的余款；后者同时给法律钱准备和银行间日常清算，以央行账簿互记借贷调整。作者作个人存银行类比，但账上央行可支付余额与本柜台现钞位置仍不同，不能把合计数字全部当该分行当场有金。需要支付地点、可转用时点及清算安排，才可回答某项提款如何兑现。

下一项call与short notice约五百六十七万，作者说主要贷货币商、股票经纪、贴现机构，多数日对日、可随时要求归还，带证券。他把银行与借款者互相欠以及证券变为currency再强调一次。要求即时归还的权利并不能保证借款者马上有现金，正如上一章自己举缺八十付不出的情境。两项加总列一千一百六十七万余，是表内结构，不可把call贷款当与现金完全同样的可用性。

投资又分英国国债及政府保证券、印度殖民及其他证券，前者注明有三万五千英镑的Stock置于公共机关，总计六百二十六万余。作者认为高等级证券增加收入、加强对存款责任的资产，并明确“假定”必要时易卖为现金。这个假定须显示，不是从表的分类已验证有足够买方和成交价。存放公共机关的那部分还可能有用途约束，原书没详细说明，专家不能擅自当全额可自由卖出，也不假造它一定被冻结的法律结果。

贴现票六百八十一万余是另一收入源，小部分直接替客户，大部分从贴现商再贴现，贴现商作商人与银行中间人。原章说中间人按某一price贴现，银行按更低price再贴，两方都赚钱，却未给利率、净款与票面现金流。price到底意指利率还是购价，没有在此明确闭合；不能悄改成更低利率来消除疑问，也不能只按现代日常购价字义就认必然印错。需要原报价定义和到期款，精确实验继续关闭。

作者将票据作为较好担保液化为merchant可用资本，扩大生产消费，视为国家利益。这是资金用途链，不证明所有贴现票确有真实交易或所有再贴现都增加净财富。第二章最佳财富的品质要求仍须应用，票据有到期、付款者和追索安排，书本分类不能替证据。行业生产与消费增量也未在这张表量出，不能将贷票余额增加直接等同某个百分点经济增长。

资产最大混合项目贷款、advance、other account和securities约一千六百二十一万，含透支和各类抵押，作者视为最不易变现、主要风险处，数量大大概风险大。绝对规模还受银行大小影响，缺分母或资产品质就不能比较另一家小银行；本章也没有给判坏的数值阈值。它应成为要求分类、期限、集中与质量资料的线索，而不是超过某个金额便自动拒绝的风险公式。

作者同时说该额仍是社区财富，若银行不贷这些财富，资本便静止如囤金，所以贷款有重要作用。它接近存款责任的一半，借款人又可对其开支票或取现金，但也欠银行贷款利息。独立按完整货币单位算贷款比所列存款约百分之四十三点一五，接近一半可视为粗略说法，不能伪造恰好五成。融资服务价值与清偿现金在不同层次，最有生产用处的贷款也未必能在同日收回。

剩下自有永久或租赁房屋约一百零二万，是银行营业场所；客户承兑对应资产前已述。房屋、证券、贷款与现金一起列满资产侧，但能否及时支付不同。尤其房屋即使有价值，可能是运营所需，不可在不损业务下迅速卖尽。作者称其自明，并非已论证立即可兑换。专家应将全部资产的经济价值、可售成本、不可任意处置限制和负债期限并列，而不是用总资产不少于账面总额完成流动性审查。

两侧复算采用一镑二十先令、一先令十二便士，统一到整数便士后再还原，Dr与Cr均为四千五百一十四万一千零四十九镑八先令二便士，现金加call与两类投资小计也闭合。原图表核对另外留审计，数值自洽不能证明原报表已审计或资产按可售现值列。独立现金对存款约百分之十五点九六，现金加call约三十一点零五，只说明选择不同资产口径可得不同数，不是作者安全门或今日监管参数。

作者归结银行制造的不是法律指定币而是社会习惯currency，连收税也接受支票；支票钱构成主要纸流通，同时还有英格兰银行票与战时财政一英镑、十先令票。后者即便并非全可兑金，法律仍给法币地位；理论上国家也可选某些银行支票为法币。这是假定的政策选择，不是此章证明所有支票已经获法币资格，更不认作今日国债、稳定币或电子凭证的制度先例保证。

他重申习惯币可偿债，但恐慌等条件能破坏其清偿能力，遂问政府是否应该提供更充分机器及在崩溃时救助。末说战争中政府确发应急票保护运转，已建先例，问题变简化；本章尚未提供全部危机措施、因果比较或长期代价。服务社会这一目的不能独自证明何种救助都合适，现代专家需实际政策权限、条件、资产与后果，不以重要性自动豁免证据。

交叉质疑可要求区分准备基金与现金、call权利与已回收款、抵押与新支付余额、对向承兑与不同责任、合计平衡与现金期限。作者若被问为什么储备比例不是唯一安全，应引用本章品质和功能，同时承认没有财务就不能认证；若被问存款全是储蓄搬运，应引用每贷增存款的原句而不替其删术语争论。缺真实报表时只解释这一典型模型，不能输出具体银行安全分、股票买卖或已校准危机概率。
